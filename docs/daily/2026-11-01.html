    From Enterprise Institutional Documents to Editable Process Models: A Hybrid LLM-Rule-Engine Architecture for Enterprise Governance#
    作者：Jia Tian、Qingyang Li、Tingrui Jiang、Zhaonian Liu、Xiaoyong Gao、Man Jiang。Preprints，2026-11-01
    🧲 物理/材料 · 其他AI×科学交叉0方向匹配0

    📄 摘要（中文翻译）：企业制度文件包含了大量面向流程的管理知识。将它们转换为结构化可编辑流程模型构成了业务流程管理 (BPM) 和治理风险合规性 (GRC) 数字化的基本任务。然而，手动流程建模耗时、从业者之间不一致且难以维护，而现有的自动化方法——无论是基于传统自然语言处理（NLP）的基于规则的方法还是最近的大语言模型（LLM）生成方法——无法同时满足语义理解准确性和输出格式一致性的双重要求，并且通常缺乏与企业审批系统的深度集成。本文遵循设计科学研究（DSR）范式，提出、实施和部署混合法学硕士和规则引擎架构（LRHA），用于从企业机构文档自动生成组织兼容的可编辑流程模型。该架构将转换任务分解为六个阶段：文本解析、元素提取、逻辑建模、规则匹配、JSON 生成和草稿输出，LLM 处理依赖于语义理解的前三个阶段，规则引擎处理依赖于确定性约束的后三个阶段，从而将语义解释与格式执行分开。针对中国企业制度文本，我们推导了一套“文本线索到流程元素”的映射规则，并定义了面向JointJS的流程模型表示规范以及十个可执行的质量验证规则。与通用的文本到 BPMN 方法不同，LRHA 在架构层面为企业治理能力提供原生支持，包括机构文本歧义解决、合规性约束验证、与现有审批 OA 系统的异步集成、版本可追溯性和审计跟踪保存。该系统已在某大型能源企业集团风控信息系统中投入生产，通过异步任务接口（任务提交、状态查询、多文件下载、主动回调），通过HMAC签名验证和幂等机制，实现与集团OA系统的端到端自动化集成。案例评估表明，对于超过40个节点和边的复杂流程，手动建模工作从几天减少到大约20分钟，只需要少量的手动微调。大规模的定量基准评估仍是未来的工作。本文有四个贡献：（1）提出并验证了法学硕士和规则引擎在自动化流程模型生成中的分工和协作机制； （2）构建适合中国企业制度文本的映射规则体系和可执行的质量验证规范； (3) 原生实现面向企业治理的架构能力，用于解决机构文本歧义、合规约束验证、OA系统集成、版本可追溯和审计跟踪保存； (4)报告了企业信息系统内混合架构的完整部署路径和工程经验，为类似组织提供可复制的参考范例。

    📖 英文原文

    Enterprise institutional documents encapsulate substantial process‑oriented management knowledge. Transforming them into structured editable process models constitutes a foundational task for business process management (BPM) and governance‑risk‑compliance (GRC) digitalization. However, manual process modeling is time-consuming, inconsistent across practitioners, and difficult to maintain, while existing automated approaches—whether rule-based methods grounded in traditional natural language processing (NLP) or recent large language model (LLM) generation methods—cannot simultaneously satisfy the dual requirements of semantic understanding accuracy and output format conformance, and typically lack deep integration with enterprise approval systems. Following the design‑science‑research (DSR) paradigm, this paper proposes, implements, and deploys a hybrid LLM and rule‑engine architecture (LRHA) for automatically generating organization‑compliant editable process models from enterprise institutional documents. The architecture decomposes the transformation task into six stages—text parsing, element extraction, logic modeling, rule matching, JSON generation, and draft output—with the LLM handling the first three stages that rely on semantic understanding and the rule engine handling the latter three stages that rely on deterministic constraints, thereby separating semantic interpretation from format enforcement. For Chinese enterprise institutional texts, we derive a set of “textual cue to process element” mapping rules and define a JointJS-oriented process model representation specification together with ten executable quality validation rules. Distinct from generic text-to-BPMN methods, LRHA provides native support for enterprise governance capabilities at the architectural level, including institutional‑text ambiguity resolution, compliance constraint validation, asynchronous integration with existing approval OA systems, version traceability, and audit trail preservation. The system has been deployed in production within the risk control information system of a large energy enterprise group, achieving end-to-end automated integration with the group’s OA system through asynchronous task interfaces (task submission, status query, multi-file download, and proactive callback), underpinned by HMAC signature verification and idempotency mechanisms. Case evaluation shows that for complex processes with over 40 nodes and edges, manual modeling work is reduced from several days to approximately 20 minutes, requiring only minor manual fine‑tuning. Large‑scale quantitative benchmark evaluation remains as future work. This paper makes four contributions: (1) it proposes and validates the division of labour and collaboration mechanism between LLMs and rule engines in automated process model generation; (2) it constructs a mapping rule system and executable quality validation specification tailored to Chinese enterprise institutional texts; (3) it natively implements enterprise‑governance‑oriented architectural capabilities for institutional‑text ambiguity resolution, compliance constraint validation, OA‑system integration, version traceability, and audit‑trail preservation; and (4) it reports the complete deployment pathway and engineering experience of the hybrid architecture within an enterprise information system, offering a replicable reference paradigm for similar organizations.
