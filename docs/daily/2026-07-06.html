今日摘要

总览：今日条目集中在量子—材料—器件交叉：图神经编码的变分量子本征求解器、扩散模型重构量子点电荷稳定图、模块化量子人工智能，与半通用机器学习原子间势预测熔盐热导率形成同一条“物理约束机器学习”主线。凝聚态方向覆盖反铁磁自旋电子学、宇称时间对称磁振子激射与反激射、单层极限钌酸锶的金属性和八重磁各向异性、层状钙钛矿铁电体的面外极化，以及二维五角双锥硼中的超导、磁性和方向性等离激元模式。应用材料侧则有石墨烯、锌铁氧体和镍铁氧体复合吸波体、咪唑衍生物缓蚀剂、孔隙材料尺度律，以及电化学地震仪非线性漂移的机载实时人工智能补偿。

热点：量子计算与量子器件自动化 → 用图神经编码提升变分量子本征求解器的可训练性和跨哈密顿量泛化，用扩散模型从稀疏测量恢复量子点电荷稳定图，用量子代码异味度量检查量子程序结构 → 典型工作为图神经量子本征求解、量子点稳定图扩散重构、量子代码结构语义度量。磁性、铁电和非厄米自旋动力学 → 围绕反铁磁自旋流、宇称时间对称磁振子激射与反激射、单层钌酸锶八重磁各向异性、层状钙钛矿面外铁电极化调控，把对称性从静态能带延伸到增益损耗和极化翻转动力学 → 典型工作为反铁磁自旋电子学综述、宇称时间对称磁振子激射、单层钌酸锶金属性研究、面外层状钙钛矿铁电体。机器学习材料物性预测与多尺度传输 → 将结构相干模型并入半通用机器学习原子间势计算熔盐热导率，用机制依赖尺度律描述孔隙材料传输，用第一性原理和蒙特卡洛模拟筛选咪唑缓蚀剂 → 典型工作为熔盐热导率机器学习势、孔隙材料尺度律、咪唑衍生物缓蚀模拟。低维与复合功能材料 → 在二维五角双锥硼中同时追踪超导、磁性和方向性等离激元，在石墨烯、锌铁氧体、镍铁氧体复合体中解析阻抗匹配、界面极化和磁损耗吸波机制 → 典型工作为二维硼同素异形体多功能物性和铁氧体石墨烯复合吸波体。
